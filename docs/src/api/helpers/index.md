# Themes and helpers

Use themes to apply consistent component styles and `info` to inspect a labelled block in context.

> [!TIP] Apply themes in scope.
> Use `#show: codly.theme(...)` before the code blocks you want to style.
> Put the rule inside a content block to limit it to that part of the document.

- [`codly.theme`](theme.md)
- [`codly.themes`](themes.md)
- [`codly.define-theme`](define-theme.md)
- [`codly.info`](info.md)

# Types

Types describe configuration values used by components. Each page lists fields, defaults, validation, and accepted shorthand forms.

> [!NOTE] Source coordinates
> Ranges and annotations use source-line positions. Whole-line highlights use
> displayed line numbers, which can change with offsets and skipped lines.
> Check each type's coordinate rules before combining these features.

# Playgrounds

Learn Codly by changing a working example. Each page combines editable Typst source with controls for common options; **Copy code** captures your edits and the current control values, ready to paste into a document.

| Playground | Try |
| --- | --- |
| [Layout and excerpts](layout.md) | Fit long lines, compare themes, select source ranges, and add a review gutter. |
| [Annotations and references](annotations.md) | Highlight characters, attach explanations, and link to code from prose. |
| [Diffs and mixed languages](diffs-and-syntax.md) | Style a patch, tune its gutters, and highlight Python inside a shell script. |

See the [API reference](../api/index.md) for complete field definitions, or [queries and show rules](../api/queries-and-show-rules.md) for custom components.

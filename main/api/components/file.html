codly.file

Creates the filename badge used beside a code block or in its header or footer.

Signature

typst code
// Create a filename badge
codly.file(
  body: str | content,
  fill: paint | none = luma(240),
  stroke: stroke | none = 0.5pt + luma(160),
  inset: length | dictionary = (x: 0.4em, y: 0.2em),
  radius: length | dictionary = 2pt,
)

// Equivalent set-rule for `codly.file`
codly.file-set_(..args)

// Equivalent show rule for `codly.file`
codly.file-show_(it => ...)

body is required and may be supplied positionally; it is the displayed filename or filename content. The remaining fields are named. codly.new documents how code blocks derive and place this badge.

codly.file-set_(..args) sets badge defaults in its scope using the fields below. codly.file-show_(it => ...) installs a show rule that receives each file badge element and returns replacement content; it does not take field overrides.

Fields

Field Type Default Meaning
body str | content Required, positional Displayed filename.
fill paint | none luma(240) Badge background; none removes the fill.
stroke stroke | none 0.5pt + luma(160) Badge border; none removes the border.
inset length | dictionary (x: 0.4em, y: 0.2em) Inner padding around the filename. A length applies uniformly; a dictionary can set axes independently.
radius length | dictionary 2pt Corner radius. A length applies uniformly; a dictionary can set corners individually.

Behavior

Pass a path to `codly.new`

When the code input is a path, codly.new reads the file, derives the badge text from its basename, and uses its extension as the language when lang is omitted. Set file or lang explicitly to override those defaults.

The badge is a box using fill, stroke, inset, and radius around body. The fields are validated against their declared types; inset and radius accept either one length or a dictionary. file-set_ applies element defaults in the surrounding scope, and file-show_ replaces the rendered badge through its callback.

codly.smart-skip

Configures which omitted source-line gaps appear as collapsed skip rows when a code block displays selected ranges.

Signature

typst code
codly.smart-skip(
  first: bool | none = none,
  last: bool | none = none,
  rest: bool | none = none,
)

All fields are named and optional.

Fields

Field Type Default / required Meaning
first none | bool none Whether to display an omission row before the first selected range.
last none | bool none Whether to display an omission row after the last selected range.
rest none | bool none Whether to display omission rows between disjoint selected ranges.

Behavior

Source coordinates

Automatic skips mark gaps between displayed source ranges; they do not change the source-line coordinates used by those ranges.

Pass this value to codly.new’s smart-skip field. A boolean casts to the same value for all three fields. A dictionary casts to this type: omitted rest defaults to false, and omitted first or last inherits rest. Thus (rest: true, first: false) enables middle skips and trailing skips, while suppressing a leading skip. With all three fields false, no automatic skips are inserted. A skip row is inserted only for a discontinuity in the displayed source lines; its represented length is the number of omitted lines.

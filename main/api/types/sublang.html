codly.sublang

Assigns a syntax-highlighting language to an inclusive range of source lines in a code block.

Signature

typst code
codly.sublang(
  start: int,
  end: int,
  lang: str,
)

All fields are required and named. The value can also be supplied as a dictionary.

Fields

Field Type Default Meaning
start int Required First source line in the range, counting from 1.
end int Required Last source line in the range, inclusive.
lang str Required Syntax-highlighting language key used for these lines.

Behavior

Source coordinates

Sublanguage ranges count one-indexed source lines and include both endpoints, independent of displayed line-number offsets.

Highlighting preserves the original lines.

Codly applies each range’s syntax language to its source lines while keeping their text and positions in the outer code block.

Pass one or more codly.sublang values in the sublangs argument to codly.new. start must be greater than zero, and end must be at least start; invalid ranges raise an error. Each range is counted from the first line of the raw block, independently of line-number offsets. Lines in the range are highlighted with the selected language’s syntax while retaining their original source text and line positions. Lines outside the ranges keep the raw block’s language. Ranges may be supplied as dictionaries with the same three fields.

Example: Basic Usage

</> Typst source 
#import "@preview/codly:2.0.0" as codly

#codly.new(
  ```sh
  echo before
  fn answer() {
      42
  }
  echo after

  ```,
  sublangs: (
    (start: 2, end: 4, lang: "rs"),
  ),
)
